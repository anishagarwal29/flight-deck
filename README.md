# Flight Deck

Offline trip app: boarding passes you can tear, a live GPS flight map with what is out your window, a passport with stamps, and a packing checklist. Works for flights anywhere.

Live at https://anishagarwal29.github.io/flight-deck/

Credits: airport data from mwgg/Airports (MIT). World map from Natural Earth via world-atlas. d3-geo, d3-array, topojson-client (ISC/BSD). Fonts: Barlow, Barlow Condensed, DM Mono (SIL OFL) via Fontsource. Exchange rates from frankfurter.app.
